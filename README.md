# BUAA OOP

本仓库用于记录北京航空航天大学面向对象程序设计课程的实验源码与配套资源。

## 仓库结构

```text
BUAA_OOP/
├── src/                # Java 实验源码
│   ├── lab_00/         # Lab 00 源码
│   └── lab_01/         # Lab 01 源码
├── figs/               # 实验相关图片
│   └── lab_01/         # Lab 01 图片资源
├── docs/               # 课程与实验文档
├── output/             # 本地生成的提交压缩包（不纳入 Git）
├── .gitignore          # Git 忽略规则
└── README.md           # 仓库说明
```
